# Company-X Inventory (Java EE)

A simple Java EE web application for managing Company-X's inventory.  
Allows CRUD operations on inventory items with a web interface built using JSP, Servlets, and EJB, and data persisted via JPA.

## Features
- Add, update, view, and delete inventory items
- Web interface using JSP & Servlets
- Business logic handled with EJB
- Persistence with JPA and a relational database

## Technologies
Java EE, JSP, Servlets, EJB, JPA, MySQL
